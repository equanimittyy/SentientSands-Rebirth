# Preset end lines

At the end of an action dialogue, the NPC says one line from the list of the end, picked at random ([End](framework.md#end)). The lines fit any NPC, because one list serves every faction and race. The lines of `!end` fit every category, because the player can end any action dialogue.

6. Nice and simple.
7. Fair enough.
8. We're done here.
9. Good. Now go on.
10. Come back if you need anything else.
