Do the Quick Start first. The Advanced Guide explains the other features of Sentient Sands Rebirth (SSR).

Quick Start
1. Install SSR
  1. Install RE_Kenshi v0.3.5 or later. Use the standard zip, not the _loose zip, and run the installer in it.
  2. Start Kenshi once. The main menu must show the RE_Kenshi version.
  3. Extract the SSR zip into Kenshi\mods\, so that Kenshi\mods\SentientSandsRebirth\SentientSands.dll exists.
  4. In the Kenshi mod launcher, select Sentient Sands Rebirth. If the original Sentient Sands is installed, disable it, because only one of the two can run.

SSR includes its own Python, so you do not install anything else.

2. Start the game

When Kenshi starts, SSR starts its server and opens this web app in your browser.

  • When your game loads, the welcome popup and the SSR HUB open. Press F8 to open the SSR HUB again.
  • If the web app does not open, press Open Web App in the SSR HUB.
  • If this page says that the server is not running, press Restart Server in the SSR HUB.

Connect a model before you talk to an NPC.

3. Connect a model

SSR needs an AI model to write what NPCs say. Choose a service and set it up first:

  • Player2: an app that gives AI to games. Set up Player2
  • OpenRouter: an online service with many models. It needs an API key. Get an OpenRouter API key
  • Ollama: runs a model on your PC. It needs no API key. Install Ollama
  • llama.cpp: an alternative to Ollama that also runs a model on your PC. It needs no API key. Install llama.cpp

Then connect it on the Models tab:

  1. Under Providers, open the card of your service, for example openrouter. If it has no card, type a name in New provider name, choose its type, and press Add. Then fill in Base URL from the docs of the service.
  2. Fill in API key. For Player2, fill in Game key.
  3. Under Profiles (Models), open a profile, or type a name in New profile name and press Add.
  4. Press List models, then choose the Model ID.
  5. Press Test. The profile shows OK when the model replies.
  6. Under Default LLM Profile, choose the profile.
  7. Press Save.

A new install uses the profile player2-default, so chats fail until Player2 runs or you choose another profile.

4. Talk to an NPC
  1. Select an NPC. You can also talk to your squad members, except the first character of your squad.
  2. Press the chat key, \ by default. You can change it on the Settings tab.
  3. To speak as another squad member, press the button with the name of the speaker until it shows that member.
  4. Choose Whisper, Talk, or Yell. Only the NPC hears a whisper. NPCs within the Talk range or the Yell range hear the other two.
  5. Type your line and press Enter. The NPC replies in a speech bubble.
  6. To close the chat window, press Enter on an empty line, or press Cancel.

To rename the NPC, type /name and the new name, for example /name Bob.

5. Campaigns

A campaign holds the memories, rumors, and world events of one playthrough. SSR creates the campaign Default on the first start.

  • To start a new playthrough, create a campaign on the Campaigns tab and choose it under Current Campaign.
  • SSR does not link a campaign to a save. Before you load the save of another playthrough, choose its campaign.
  • When you load an older save of the same playthrough, press Cull future data, or Cull Future Data in the SSR HUB. NPCs then forget what happened after the time of the save. The game must run for a cull.
6. The SSR HUB

Press F8 in the game to open the SSR HUB.

  • Dialogue Library: the NPCs that you talked to, with their profiles and conversation logs.
  • Events: the kills, captures, and rumors of the campaign.
  • Cull Future Data: makes NPCs forget what happened after the current game time.
  • Open Web App: opens this web app in a new browser tab.
  • Restart Server: restarts the SSR server, for example when this web app says that the server is not running.
  • Welcome Popup: shows the welcome popup again.
7. Troubleshooting
  • The NPC could not respond: on the Models tab, press Test on your default profile. If the test fails, check the API key and the Model ID.
  • The chat key does nothing: select an NPC first, and close the Dialogue Library. The first character of your squad cannot be a chat target.
  • This page says that the server is not running: press Restart Server in the SSR HUB.
  • Replies are slow with a local model: see Local models in the Advanced Guide.
  • A bug report: attach SentientSands_SDK.log from the Kenshi folder and server\logs\server.log from the SSR folder.
Advanced Guide
Tasks and fallbacks

Each task under Tasks (Advanced) on the Models tab is one kind of AI call: Chat, Radiant conversations, NPC profile, Rumors, and Conversation memories.

  • A task tries its profiles in order until one replies. Use Add a fallback… to add a profile, and the arrows to change the order.
  • To use another model for one task, add its profile to that task and move it above the default.
  • The game waits only 60 s for a reply, so keep each Deadline (s) under 60.
  • Max tokens limits the length of a reply. Temperature sets how varied the replies are.
  • Extra request parameters (JSON) on a profile sends other model settings, for example {"top_p": 0.9}.
Local models

A local server, such as Ollama, llama.cpp, or LM Studio, runs the model on your PC. It needs no API key.

  1. Install the server and download a model. Install Ollama or Install llama.cpp
  2. On the Models tab, open the provider ollama. For llama.cpp or LM Studio, add an OpenAI-compatible provider. Its Base URL is the address that the server shows, followed by /v1, for example http://localhost:8080/v1 for llama.cpp or http://localhost:1234/v1 for LM Studio.
  3. Set the Model ID to the name of your model, press Test, and choose the profile under Default LLM Profile.

A local model is slower and reads less text. Lower Retrieval slots on the Settings tab, because each slot adds up to about 250 tokens to each line that you say.

How NPCs remember
  • When you stop chatting for the Conversation timeout (3 minutes by default), SSR writes a short summary of each conversation. Each NPC in the conversation remembers the summary.
  • An NPC keeps its 5 newest conversations in mind. It recalls an older one, or one that it overheard, when your line touches it.
  • To change what NPCs remember, edit or delete the Memorised Summary on Editor > Campaign Canon > Dialogue & Memories. A delete makes the NPCs forget the conversation.
  • Retrieval slots, Memory slots, and Retrieval cooldown on the Settings tab set how much an NPC recalls with each line.
Rumors and events
  • When your squad kills or captures a unique character, such as Tinfist, SSR records an event. It writes a rumor for the event when you stop chatting.
  • NPCs mention the 3 newest rumors, and recall an older one when your line touches it.
  • To add a rumor of your own, type it in Add a custom rumour on Editor > Campaign Canon > Events, and press Add.
  • At most once each Radiant rumor timer (30 minutes by default), SSR turns a story that comes back in your conversations into an Auto event.
  • Press Generate Rumor to write a rumor now, with optional instructions. Then edit the text and press Save.

The Events window of the SSR HUB does the same in the game.

Radiant conversations
  • Each Radiant chat timer (10 minutes of unpaused time by default), 3 to 5 of your characters who stand together talk. The topic is a memory that they share, the place, or a rumor.
  • Sometimes NPCs of one squad who relax at a bar talk about a rumor instead. NPC radiant chance sets how often.
  • Characters who fought in the last 3 game hours do not talk.
  • To start a radiant conversation now, press Trigger Radiant in the chat window.
  • To stop them, clear Radiant conversations on the Settings tab.
NPC profiles and bios
  • When you meet an NPC, SSR gives it a provisional profile: a rolled personality, backstory, and way of speech.
  • After Chats before a bio (5 by default), the AI writes the full bio from your chats.
  • To write a bio now, press Generate Bio in the Dialogue Library, or on the character in Editor > Campaign Canon > Database. You can add instructions, for example "a former slave who distrusts every noble".
  • Most NPCs get a name, for example Barman Arleen. To rename an NPC, change its Name in the Editor.
World canon

Editor > Campaign Canon > Database holds what the NPCs of the current campaign know about the world. A change applies from the next chat.

  • Every NPC knows the overview and the factions. An NPC also gets a history entry, a race, a location, or a region when your line names or touches it.
  • Knowledge Level sets who knows an entry. Global: every NPC. Limited: NPCs whose faction, race, home, or travels link to it. Secret: only the characters, factions, and races in Known by.
  • Show seeded data shows the entries that the campaign copied from its template.
World templates
  • A new campaign starts as a copy of a world template. A change to a template applies only to the campaigns that you create later.
  • SSR Vanilla is read-only. On Editor > Templates, press Duplicate to make a copy that you can edit.
  • Export saves a template as one .json file that you can share. Import adds a template from such a file.
Prompts
  • The Prompts tab holds the instructions that SSR sends to the AI. They apply to every campaign.
  • An edited prompt shows Edited. Use default puts back the text that SSR ships.
  • Default changed means that an SSR update changed the default of an edited prompt. Compare your text with the new default.
  • Keep the words in braces, such as {name}. SSR fills them in.
Logs and tests
  • Log level on the Settings tab sets how much SSR writes to its logs. DEBUG writes the most, and also shows Test search on the Editor tab.
  • Test search shows which lore entries, memories, and rumors an NPC gets with a line that you say.
  • SentientSands_SDK.log in the Kenshi folder holds the current game, and SentientSands_SDK.old.log the game before.
  • server\logs\server.log in the SSR folder holds the server log. At DEBUG, server\logs\llm.log holds each prompt and reply.
Updates and backups
  • The SSR zip holds none of your data, so an update keeps your API keys, settings, edited prompts, templates, and campaigns.
  • To back up or share a campaign, copy its folder in server\data\campaigns\.
